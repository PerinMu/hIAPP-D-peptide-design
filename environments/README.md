# Production GPU environment snapshots

These credential-free `pip freeze` files were recovered from the surviving
cloud environments on 2026-08-15. They complement the portable installation
instructions in the main README and the CPU evaluator environment in
`environment.yml`.

- `boltzgen-production-pip-freeze.txt`: BoltzGen/BoltzIF environment.
- `boltz2-production-pip-freeze.txt`: Boltz-2 prediction environment.

The BoltzGen version is also confirmed by a historical inverse-folding log.
Boltz 2.2.1 is labeled as a recovered environment snapshot because historical
prediction logs did not print the version. See
`docs/PRODUCTION_ENVIRONMENT.md` for hashes, hardware, and evidence boundaries.
